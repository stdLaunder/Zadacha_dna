# Как оформлять серию из нескольких частей

Этот шаблон рассчитан на Quartz 5 и переиспользуемый компонент `SeriesNavigation`.

## Структура

```text
content/
  series/
    my-topic/
      index.md
      part-1.md
      part-2.md
      part-3.md
      part-4.md
      part-5.md
      part-6.md
```

## Главная страница цикла (`index.md`)

```markdown
---
title: "Название математического цикла"
tags:
  - теория-чисел
---

# Название математического цикла

Краткое введение и объяснение порядка чтения.

1. [Часть 1. Введение](part-1)
2. [Часть 2. Основные идеи](part-2)
3. [Часть 3. Продолжение](part-3)
4. [Часть 4. Применения](part-4)
5. [Часть 5. Ещё одно доказательство](part-5)
6. [Часть 6. Финал](part-6)
```

## Frontmatter каждой части

```yaml
---
title: "Часть 1. Введение"
series: "my-topic"
seriesTitle: "Название математического цикла"
seriesPart: 1
seriesIndex: "series/my-topic/index"
tags:
  - теория-чисел
---
```

Для остальных файлов меняется `title` и `seriesPart` (от 2 до 6).
Все части должны использовать один и тот же `series`.

После заполнения страниц автоматически появится навигация **над статьёй и под ней**:
- номер текущей части;
- номера всех доступных частей;
- ссылки «Предыдущая часть», «Все части», «Следующая часть».

Если одна часть ещё не опубликована, в навигации будут только те, что действительно существуют.

Обычные статьи без поля `series` не изменятся.

**Важно:** изменение `seriesIndex` должно совпадать с реальным URL страницы оглавления. Указывай путь от корня content, без расширения `.md`.
